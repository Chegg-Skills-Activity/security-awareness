# Security Decision Challenge

A short, browser-based interactive simulation where learners face everyday workplace security situations and see the consequences of their choices.

## Objective

Reinforce information security and ISO-aligned decision-making through workplace scenarios and risk-based choices.

## What learners do

- Work through a series of realistic workplace scenarios involving information security and compliance
- Choose how to respond to each situation from a set of possible actions
- See the outcome of each decision and understand why it was (or wasn't) the right call
- Connect day-to-day choices to risk management and ISO-aligned security practices

## Format

- Runs directly in a web browser — no installation or setup required
- Approximately 10–15 minutes to complete
- Self-paced, no timer

## Access note

This simulation is a complementary learning component integrated into the cybersecurity curriculum. It is intended to be completed at its designated point within the coursework, not as standalone material.
